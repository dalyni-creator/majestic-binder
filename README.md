# Majestic RP Binder (+EMS сценарии)

Биндер и таймер дежурств для Majestic RP. Тёмный безрамочный интерфейс, профили сценариев и игровой оверлей.

**[Скачать последнюю версию для Windows](https://github.com/dalyni-creator/majestic-binder/releases/latest)**

## Возможности

- Создание профилей с готовыми сценариями, задержками, горячими клавишами и возможность ручного дополнения.
- Два режима работы: моментальная вставка и с симуляцией ручного ввода.
- Блокировка постороннего ввода во время работы сценария и настраиваемый экстренный стоп.
- Экранная клавиатура для выбора комбинаций.
- Оверлей со списком сценариев и подсветкой активного.
- Таймер с паузой, продлением и авто-скриншотом по окончании.
- Обмен профилями через код или JSON: «Поделиться» — в меню правой кнопки мыши; импорт — иконка рядом с «ПРОФИЛИ».
- Фоновая проверка обновлений с установкой через обычный мастер.

## Установка

1. Откройте [последний релиз](https://github.com/dalyni-creator/majestic-binder/releases/latest).
2. Скачайте `MajesticBinder-Setup-2.11.0-x64.exe` и запустите установщик.
3. Откройте программу с ярлыка. При первом запуске выберите готовые профили или «С нуля».

Поддерживаются **Windows 10 1809 и новее / Windows 11, 64 бита**. Нужны .NET Framework 4.7.2 или новее и Microsoft WebView2. Установщик добавит WebView2 при его отсутствии; для этого потребуется интернет.

## Быстрый старт

Выберите профиль, создайте сценарий и назначьте сочетание. Отредактируйте шаги и задержки. Проверяйте текст во встроенном предпросмотре, затем переключитесь в игру и нажмите сочетание.

Во время автоматических шагов клавиатура защищена от случайного ввода. **F12** — экстренный стоп по умолчанию; кнопку можно изменить справа. На шагах с ручным дополнением допишите текст и нажмите Enter.

Глаз в шапке показывает или скрывает оверлей. Для кнопок верхней строки включите курсор в игре. Оверлей отображается поверх игры в оконном режиме или в окне без рамок.

Таймеру назначьте ту же клавишу скриншота, что в игре или Steam. Биндер не снимает экран самостоятельно и не создаёт отдельную папку со скриншотами.

## Обновления

Программа проверяет новые версии в фоне. Номер версии внизу слева запускает ручную проверку. При появлении обновления нажмите «Обновить», затем «Установить». Перед установкой проверяются размер и SHA-256 файла. Профили и настройки сохраняются.

Для перехода с прежних тестовых сборок установите эту версию вручную один раз. Дальнейшие обновления доступны из программы.

## Данные и удаление

Профили и настройки: `%LOCALAPPDATA%\MajesticRPBinder`.

Удаление: **Параметры Windows → Приложения → Majestic RP Binder → Удалить**. Пользовательские профили сохраняются для повторной установки.

## Исходники

В релизах доступны установщик, `update.json` и архив исходников. В архиве находятся простой файл `ИНСТРУКЦИЯ.txt`, код, ресурсы, тесты и скрипт сборки для Windows. Репозиторий хранит описание, историю изменений и автоматическую сборку релизов, как Majestic Organizer.
